Ingress Control Plane

Leadership brief: how specialist AI agents collaborate to deliver safe, self-service ingress changes

The problem

Onboarding an application to the enterprise ingress platform today takes days of tickets, specialist knowledge (Kubernetes, DNS, TLS, WAF) and manual compliance sign-off. Teams hesitate to migrate because a bad routing change can take down production.

The solution in one paragraph

A developer describes what they need in plain English. A coordinated team of specialist AI agents analyses the live environment in parallel, checks policy, scores risk, drafts the exact configuration change and pre-computes a rollback. A human approver signs off, and only then does a tightly-scoped execution agent apply the change progressively, watching health probes and rolling back automatically if anything degrades. Every handoff is recorded in a tamper-evident audit log.

Platform team becomes a bottleneckSecurity, FinOps and Platform teams add new specialist agents at runtime, with no code deploy.
Design principle: AI reasons and recommends; deterministic code and humans decide and execute. The AI never holds write credentials until a signed human approval exists.

How the agents interact

Work flows top to bottom. Each stage hands structured, validated data to the next, and read-only analysis is separated from write execution.

Extending governance without engineering effort

  1. Define a specialist in Agent Studio: goal, read-only tools and the structured outputs it must produce.
  2. Chain it to earlier agents' outputs; the system validates the dependency graph and rejects loops or write-tool escalation.
  3. It runs automatically in the correct stage on every workflow, with no redeploy.
  4. It can veto or raise risk, pausing the change for human sign-off but never bypassing security boundaries.

Where an agent framework such as Strands fits

An open-source agent SDK (for example, Strands Agents) could serve as the runtime inside each agent node: model-agnostic access (Bedrock, Anthropic, OpenAI, Gemini), structured output, tool and MCP connectivity, tracing and evaluation. The orchestration, approval, audit and rollout logic remains in-house, as it is the core control and differentiator. See docs/strands-agents-evaluation.md.
